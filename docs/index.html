U1 Farm Control
Features

Everything you check on the printer, from your desk.

Built for people running more than one U1. Every printer gets the same detailed card, side by side.

📊

Live tray progress

One icon per printer next to the clock. It shows the percentage, fills as the print runs and changes color for paused, done, error and offline.

📷

Built-in camera

The stock U1 camera doesn't stream on its own. The app wakes it up automatically and shows the live view.

⏱

Time and progress

Remaining time, finish time, layer, filament used and live speed, plus the slicer thumbnail of the current job.

🎨

All 4 toolheads

Filament color and type for every head, nozzle temperatures, and which head is printing right now.

⏏

Filament unload

Unload one head, the heads you select, or all four, using the printer's own unload sequence.

🔔

Controls and alerts

Pause, resume, cancel, light, speed, flow, fan and E-stop. Desktop notifications when a print finishes or fails.

Dashboard

One card per printer, all the detail.

Each card shows what the printer is doing right now, and everything you need to act on it.

  • Live camera with full-screen view
  • Progress ring with remaining time and finish time
  • Active toolhead, temperatures and filament colors
  • Bed, chamber and part-fan readings
  • Speed, flow and fan sliders while printing
  • Start any G-code file on the printer, browse print history
Filament

Unload filament without walking to the printer.

See what's loaded in every head and unload it with one click. The app heats the head and runs the same unload sequence the touchscreen uses. It's locked while a print is running.

Setup

Add a printer by its IP. That's it.

No account and no cloud. The app talks straight to each printer on your local network over its Moonraker API. Pick your language, choose one tray icon per printer or one for all, and start with Windows if you like.

Get started

Up and running in a minute.

Download

Grab the installer or the portable exe from the latest release.

Add your printers

Enter each U1's local IP address. You'll find it in the printer's network settings or your router's device list.

Minimize

The window goes to the tray. Glance at the clock to see how every print is doing.

FAQ

Questions

Does it need custom firmware?

No. It works with the stock Snapmaker U1 firmware (tested with 2.0.0.205). Your PC and printers just need to be on the same local network.

Windows says the app is unrecognized. Is it safe?

The executables aren't code-signed yet, so SmartScreen shows a warning for new downloads. Click More info → Run anyway. The full source is on GitHub and every release is built by GitHub Actions from that source.

Why is the camera only about 1 frame per second?

That's the limit of the stock firmware's camera snapshot. The app wakes the camera up and keeps it running while the dashboard is open, and stops when the window is hidden.

Does it work on macOS or Linux?

Only Windows builds are published today. The app is built with Electron, so other platforms are possible. Contributions are welcome.

Is this an official Snapmaker app?

No. It's a free community project, not affiliated with or endorsed by Snapmaker. Actions like filament unload and emergency stop move your printer; use them at your own risk.
