Features

Everything you check on your Snapmaker U1, from your desk.

Built for makers running one or more Snapmaker U1 printers. Every printer gets the same detailed card, side by side, updated every two seconds.

📊

Live tray progress

One icon per Snapmaker U1 next to the clock. It shows the percentage, fills as the print runs and changes color for paused, done, error and offline.

📷

Snapmaker U1 camera

The stock Snapmaker U1 camera doesn't stream on its own. The app wakes it up automatically and shows the live view.

⏱

Time and progress

Remaining time, finish time, layer, filament used and live speed, plus the slicer thumbnail of the current job.

🎨

All 4 toolheads

Built for the U1 toolchanger: filament color and type for every head, nozzle temperatures, and which head is printing right now.

⏏

Remote filament unload

Unload one head, the heads you select, or all four, using the Snapmaker U1's own unload sequence.

🔔

Controls and alerts

Pause, resume, cancel, light, speed, flow, fan and E-stop. Desktop notifications when a print finishes or fails.

Dashboard

One card per Snapmaker U1, all the detail.

Each card shows what the printer is doing right now, and everything you need to act on it.

  • Live camera with full-screen view
  • Progress ring with remaining time and finish time
  • Active toolhead, temperatures and filament colors
  • Bed, chamber and part-fan readings
  • Speed, flow and fan sliders while printing
  • Start any G-code file on the printer, browse print history
Filament

Unload Snapmaker U1 filament without walking to the printer.

See what's loaded in every head and unload it with one click. The app heats the head and runs the same unload sequence as the Snapmaker U1 touchscreen. It's locked while a print is running.

Setup

Add a Snapmaker U1 by its IP. That's it.

No account and no cloud. The Snapmaker U1 runs Klipper with Moonraker, and the app talks straight to each printer on your local network over the Moonraker API. No custom firmware needed. Pick your language, choose one tray icon per printer or one for all, and start with Windows if you like.

Enter each Snapmaker U1's local IP address. You'll find it in the printer's network settings or your router's device list.

FAQ

Snapmaker U1 Farm Control FAQ

Does U1 Farm Control need custom Snapmaker U1 firmware?

No. It works with the stock Snapmaker U1 firmware (tested with 2.0.0.205). Your PC and printers just need to be on the same local network.

Windows says the app is unrecognized. Is it safe?

The executables aren't code-signed yet, so SmartScreen shows a warning for new downloads. Click More info → Run anyway. The full source is on GitHub and every release is built by GitHub Actions from that source.

Why is the Snapmaker U1 camera only about 1 frame per second?

That's the limit of the stock Snapmaker U1 firmware's camera snapshot. The app wakes the camera up and keeps it running while the dashboard is open, and stops when the window is hidden.

How many Snapmaker U1 printers can I monitor?

As many as you like. Each Snapmaker U1 gets its own card on the dashboard and, optionally, its own tray icon.

Does it work on macOS or Linux?

Only Windows builds are published today. The app is built with Electron, so other platforms are possible. Contributions are welcome.

Is this an official Snapmaker app?

No. It's a free community project for Snapmaker U1 owners, not affiliated with or endorsed by Snapmaker. Actions like filament unload and emergency stop move your printer; use them at your own risk.
